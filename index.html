PRJ-03 Security Tool

USB Physical Security Tool

Built during my internship. A Python/Tkinter GUI that toggles USB storage access via the Windows registry (HKLM\SYSTEM\CurrentControlSet\Services\USBSTOR). Auth is PBKDF2-HMAC-SHA256 with 260k iterations and constant-time comparison, with lockout after failed attempts and full audit logging. Packaged standalone with PyInstaller.
